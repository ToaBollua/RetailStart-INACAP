1. PostgreSQL (Data Warehouse Estrella)
----------------------------------------
- Contenedor: srv-db-postgres-primary
- Puerto Host: 5434 (Mapea a 5432 interno)
- Base de Datos: retail_dw
- Usuario: retail_user
- Contraseña: retail_pass
- Schema: public

2. MongoDB (Data Lake NoSQL)
-----------------------------
- Contenedor: srv-db-mongo-primary
- Puerto Host: 27018 (Mapea a 27017 interno)
- Base de Datos: retail_lake
- Colección: raw_events
- Usuario Root: root
- Contraseña Root: rootpass
- Replicaset: rs0
- Llave Replicaset: replicasetkey123
- URI de conexión externa:
  mongodb://root:rootpass@localhost:27018/?replicaSet=rs0&authSource=admin

3. Interfaces y Portales Web (Dashboard BI)
--------------------------------------------
- Dashboard BI (Django): http://localhost:8083
- PostgreSQL Adminer (SQL): http://localhost:8085 (Autologin habilitado)
- MongoDB Express (NoSQL): http://localhost:8086 (Basic Auth deshabilitado)
- Dashboard Cliente: http://localhost:8082
- API Backend (Ingesta): http://localhost:8000
  - Documentación Swagger: http://localhost:8000/docs

4. Comandos de Utilidad Rápida
-------------------------------
- Limpiar y Repoblar todo (10 días): ./reset_db.sh
- Levantar clúster completo: docker compose up -d
- Bajar clúster completo: docker compose down -v
